# 1. Введение в TC-LIST

В современной информатике и программировании ключевое значение имеет эффективность обработки данных. Выбор правильной структуры данных является фундаментом для создания производительного и надежного продукта. Одной из базовых структур данных являются связные списки.

В отличие от статических массивов, связные списки позволяют эффективно управлять памятью, добавляя и удаляя элементы без необходимости перераспределения всего блока данных. Особое место среди них занимает двусвязный список. Благодаря наличию указателей как на следующий, так и на предыдущий элементы, данная структура обеспечивает высокую гибкость при обходе данных в обоих направлениях и эффективные операции удаления узлов.

# 2. Возможности

Основные функции:

1) tc_init() - инициализация двусвязного списка

   Функция работает со структурой списка, предварительно заполненной всеми нулевыми значениями (иначе инициализация прервется во избежание потенциальной потери данных)


2) tc_pop() - удаление элемента из списка по индексу с возвращением его значения

    Частные случаи (и соответствующие команды):

    tc_pop_first() - удаление «хвоста» (начального элемента) списка

    tc_pop_last() - удаление «головы» (конечного элемента) списка


3) tc_insert_index() - вставка нового элемента после элемента, заданного индексом

    Частные случаи (и соответствующие команды):

    tc_insert_first() - вставка в хвост

    tc_insert_last() - вставка в голову

    tc_insert_number() - вставка по номеру в списке


4) tc_dump_terminal() - Краткий дамп списка в терминал

5) tc_verify() - Проверка списка (по умолчанию вызывается перед любым действием со списком - добавлением/удалением элемента); Функцию можно «отключить», отключив макрос AUTO_VERIFY
 

6) tc_make_html() - Полный дамп списка в html-файл (по умолчанию вызывается в ходе каждой проверки списка); Функцию также можно «отключить», отключив макрос AUTO_DUMP


# 3. Требования и сборка

Для запуска программы потребуется компилятор языка C/C++ (К примеру, g++/clang++)

Также понадобится сторонняя программа для построения графов - [Graphviz](https://www.graphviz.org/) (все инструкции для установки можно найти на сайте Graphviz)

Пусть main_file.cpp - основной файл для работы

Тогда файлы main_file.cpp ; tclist.cpp ; tclist_operations.cpp следует расположить в одной папке

В этой же папке следует создать папку с названием debug_pictures (в эту папку будут сохраняться png-файлы, нужные для полноценного дампа)

после этого следует ввести в терминале уже привычную команду 
```bash
g++ .\main_file.cpp -o .\main_file.exe
```

После этого в папке должен появится файл main_file.exe


# 4. Запуск

Запуск, уже привычно, производится командой 
```bash
.\main_file.exe
```

После чего в папке должны появиться файлы graph.dot и graph.htm, а папка debug_pictures заполнится картинками для дампа


# 5. Содержимое файла graph.htm

На странице отображаются номер дампа, таблица с полной характеристикой каждого узла и две схемы элементов списка

Первая схема - отображение элементов в порядке их индексов

Вторая схема - отображение с минимальным количеством пересечений стрелок и более логичной перегруппировкой элементов

Черными стрелками показаны связи между занятыми элементами; Зелеными - связи между свободными элементами; Красным - ошибки в связях

(В зависимости от конкретной ситуации обе схемы могут оказаться удобными, из-за чего было принято решение оставить оба варианта)
